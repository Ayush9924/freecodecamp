API Project: URL Shortener Microservice

Usage:

Enter a URL to create a shortened version:

Shorten a URL

Example Usage:

POST /api/shorturl

Request body: {"url":"https://www.freecodecamp.org"}

Response: {"original_url":"https://www.freecodecamp.org","short_url":1}

Then visit: /api/shorturl/1 to redirect to original URL
